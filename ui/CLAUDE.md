# AGENTS.md

## Project

**KServe Nexus** — KServe inference service management platform. Monorepo with Go backend (Gin + Kubernetes controller-runtime) and React frontend (Ant Design Pro v6 on Umi Max v4).

- **Backend**: Go 1.25, Gin HTTP server on port 5109, K8s controller-runtime manager for cached read access to KServe/Knative/Istio/Gateway API/KEDA resources.
- **Frontend**: Ant Design Pro v6, React 19, TypeScript 6, antd v6, ProComponents v3, Tailwind CSS v4.

## Project Structure

```

  cmd/main.go                  — Go entrypoint, starts Gin server + K8s manager
  internal/

    handler/

  kind.init.sh                 — Image preload script for Kind
  ui/                          — React frontend (this directory)
    src/
    config/
    cloudflare-worker/
    ...
```

## Backend Architecture

### API Endpoints (Gin, port 5109)

**Inference Services** (`/kserve/api`):
| Method | Path | Description |
|--------|------|-------------|
| GET | `/namespace` | List K8s namespaces |
| GET | `/config` | Get KServe ConfigMap (`inferenceservice-config`) |
| GET | `/isvc` | List InferenceServices (`?namespace=all`) |
| GET | `/isvc/:name` | Get ISVC detail + topology graph (`?kind=grafana` → DOT format) |
| GET | `/graph` | List/Get InferenceGraphs |
| GET | `/graph/:name` | Get InferenceGraph with route topology |
| GET | `/llmisvc` | List LLMInferenceServices (v1alpha2) |
| GET | `/llmisvc/:name` | Get LLMISVC detail + topology |
| GET | `/dashboard/stats` | Aggregated stats (total/normal/abnormal counts) |

**CRD Access** (`/crd`):
| Method | Path | Description |
|--------|------|-------------|
| GET | `/pod` | Get pod details (stub) |

### K8s Resource Coverage

- **KServe**: InferenceService (v1beta1), InferenceGraph (v1alpha1), LLMInferenceService (v1alpha2)
- **Deployment modes**: Standard (Service → Deployment → HPA/KEDA → Pod) and Knative (Service → Revision → Configuration → ServerlessService → Deployment → Pod)
- **Autoscaling**: HPA (autoscaling/v2), KEDA ScaledObject (v1alpha1)
- **Networking**: Gateway API (HTTPRoute, Gateway), Istio (VirtualService, Gateway), Envoy AI Gateway (AIGatewayRoute, InferencePool)
- **Storage**: PVC → PV → StorageClass, ServiceAccount → Secret, ClusterStorageContainer

### Response Format

All API responses use standardized JSON: `{ code: 0|1, message: string, data: any }`. Always HTTP 200.

## Critical Rules

- **Never edit `src/services/ant-design-pro/`** — auto-generated by `npm run openapi`
- **Biome only** — no ESLint, no Prettier
- **`npm run lint` and `npx antd lint ./src` both must pass** before commit
- **Conventional commits** enforced by commitlint (husky `commit-msg` hook)
- **TypeScript strict** — `tsc --noEmit` must pass (see `tsconfig.json`)
- **Node ≥ 20** · **npm** with `package-lock.json` (not yarn/pnpm — `pnpm-lock.yaml` exists but is unused)
- `.npmrc` sets `legacy-peer-deps=true` — required for `npm install` to succeed
- **`.umi` dirs are auto-generated** (`src/.umi`, `src/.umi-test`, etc.) — delete them and restart the dev server if it breaks
- **Pre-commit**: `lint-staged` runs Biome on staged files; `commit-msg` runs commitlint

## UI Architecture

### Framework & Entry Points

Umi Max v4 convention-over-config framework. Convention files in `src/`:

| File | Role |
|------|------|
| `app.tsx` | Runtime config: `getInitialState`, layout, request config |
| `access.ts` | Permissions (`canAdmin`, etc.) |
| `global.tsx` | Global side effects, providers |
| `loading.tsx` | Custom loading component |
| `requestErrorConfig.ts` | Request error handling |
| `global.style.ts` | Global styles (antd-style) |
| `tailwind.css` | Tailwind CSS entry |

Build config: `config/config.ts` (defineConfig). Routes: `config/routes.ts`.

### Umi Max Plugins in Use

model, initialState, layout, moment2dayjs, locale, antd, request, reactQuery, access, analytics (GA4), openAPI (`@umijs/max-plugin-openapi`), requestRecord (`@umijs/request-record`)

### Module Aliases

`@/*` → `src/*`, `@@/*` → `src/.umi/*`, `@root/*` → `./*`

### Pages

| Page | Path | Description |
|------|------|-------------|
| `Welcome.tsx` | `/welcome` | Landing page with Markdown cheatsheet via `@ant-design/x-markdown` |
| `Admin.tsx` | `/admin/sub-page` | Admin-only page (protected by `canAdmin`) |
| `user/login/` | `/user/login` | Login page (account, mobile captcha, QR code) |
| `table-list/` | `/list` | ProTable CRUD example with React Query mutations |
| `chatbot/` | (routed) | AI chatbot using `@ant-design/x` (Bubble, Sender, Think, SSE streaming) |
| `exception/403/` | — | 403 Forbidden |
| `exception/404/` | `./*` | 404 Not Found (catch-all) |
| `exception/500/` | — | 500 Server Error |

### Auth

`getInitialState()` in `src/app.tsx` fetches `GET /api/currentUser`. On 401 → redirect `/user/login` with return URL. `src/access.ts`: `canAdmin = currentUser.access === 'admin'`. Mock creds: `admin`/`ant.design` or `user`/`ant.design`.

### State Management

- `useModel('@@initialState')` — currentUser, settings, settingDrawerOpen
- ProTable `request` prop — most data loading
- `@tanstack/react-query` — complex server state (enabled via `reactQuery` plugin)

### Styling Priority

Tailwind CSS v4 (layout) → antd-style v4 / `createStyles` (theme tokens) → CSS Modules → Less (legacy only)

### Request Layer

Built-in `request` from `@umijs/max`, configured in `src/requestErrorConfig.ts`. Base URL: empty string in dev (proxy via `config/proxy.ts`), `https://pro-api.ant-design-demo.workers.dev` in production.

### i18n

Locales in `src/locales/`. Default: `zh-CN`. `useIntl().formatMessage({ id, defaultMessage })`.

### Mock

`mock/` (global) + `src/pages/**/_mock.ts` (co-located, auto-discovered). Express-style handlers. Mock config: `config/config.ts` → `mock.include`/`mock.exclude`.

### Build & Deployment

- `max build` wraps utoopack (`@utoo/pack`). Custom loader for `.md` files (raw import via `config/md-raw-loader.cjs`).
- `exportStatic` enabled for static deployment.
- Production base URL: Cloudflare Worker. CI deploys: `build` → `deploy`.
- `hash: true` for cache-busting. `fastRefresh`, `routePrefetch`, `manifest` enabled.

### Cloudflare Worker

`cloudflare-worker/` — separate Hono app with own `package.json` and `wrangler.toml`. Not an npm workspace. Serves as production API backend with mock routes under `/api/` (user, dashboard, table, list, monitor, notices, profile, settings).

### Key Dependencies

`antd` v6, `@ant-design/pro-components` v3, `@ant-design/x` v2 (AI chatbot), `@ant-design/x-markdown`, `@tanstack/react-query` v5, `antd-style` v4, `dayjs` v1, `highlight.js` v11, `@umijs/max` v4, `typescript` v6, `tailwindcss` v4, `jest` v30, `@biomejs/biome` v2

## Page Co-location

Each page dir under `src/pages/`: `index.tsx`, optional `service.ts`, `_mock.ts`, `data.d.ts`, style files. Keep page-specific code with the page.

## Testing

- **Framework**: Jest with jsdom (`jest-environment-jsdom`)
- **Config**: `jest.config.ts` extends Umi's `createConfig({ target: 'browser' })`
- **Mocks**: `tests/__mocks__/` — `.md` files mapped to raw text mock, `mermaid` library mocked
- **Setup**: `tests/setupTests.jsx` runs before each test suite
- **Globals**: `localStorage: null`, `__APP_VERSION__: 'test'`, `__UMI_VERSION__`, `__UTOO_VERSION__`
- **Snapshots**: `npm run test:update` (`jest -u`)
